Festivos: cómo cargar los calendarios

Selecciona una zona y carga su archivo ICS descargado de la fuente oficial. Repite la operación para cada zona. Los festivos se guardan en este navegador para esa zona. El HTML no consulta directamente la web externa: así evitamos depender de permisos CORS o de una API que pueda cambiar.

Importante: esta primera versión no trae todavía festivos oficiales precargados. Hasta importar los archivos ICS, los días aparecerán como laborables o fin de semana. En Galicia, el calendario local debe corresponder al municipio concreto que utilicéis.
